Panduan Join

Masuk ke Server Dalam Hitungan Detik

Pilih platform kamu, salin IP, masukkan port, lalu langsung join ke dunia NANSMP.

Mobile / Bedrock

  • 1Buka Minecraft, masuk ke menu Play, lalu pilih tab Servers.
  • 2Klik tombol Add Server atau Tambah Server.
  • 3Masukkan IP nansmp.net dan port 19132.
  • 4Klik Save, lalu tekan Play untuk bergabung.

PC / Java

  • 1Buka Minecraft Java, lalu pilih menu Multiplayer.
  • 2Klik Add Server untuk menambahkan server baru.
  • 3Masukkan address nansmp.net.
  • 4Klik Done, pilih NANSMP, lalu join.
